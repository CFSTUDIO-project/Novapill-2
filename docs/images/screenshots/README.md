# Screenshots

Real device screenshots go here. None are included in this drop.

The pictures in `docs/images/` are design illustrations drawn from the layout code. They are not screenshots of the running app and are captioned as such in the README.

When you have run the app on a phone, add the files below and reference them from the README:

- `idle.png` — idle pill (clock, weather, battery)
- `quick_panel.png` — quick panel, page 1 and 2
- `notification.png` — notification peek
- `recorder.png` — recorder card while recording and after saving

Crop out personal information (names, numbers, message text) before committing.
